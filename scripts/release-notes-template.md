## 安装

```bash
curl -fsSL https://github.com/xcanwin/manyoyo/raw/main/scripts/install.sh | sh
```

已安装的用户：`manyoyo update`。
手动下载：选 `manyoyo-<版本>-<系统>-<芯片>.run`，用 `sh` 运行。`-app.tar.gz` 是 `manyoyo update` 自动用的，不需要手动下载。

## Install

```bash
curl -fsSL https://github.com/xcanwin/manyoyo/raw/main/scripts/install.sh | sh
```
